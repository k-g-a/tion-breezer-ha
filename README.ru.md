# Tion Breezer 2026 для Home Assistant

[English](README.md)

Управление бризерами Tion 3S, 4S и Lite по Bluetooth. Библиотека протокола входит в комплект. Минимальная поддерживаемая версия — **Home Assistant Core 2025.6.0**. У сопровождающего четыре Tion 4S стабильно работают на Core 2026.11.2 под прежним доменом. Для всех четырёх потребовалось ручное сопряжение через `bluetoothctl`. См. [инструкцию по Bluetooth](docs/bluetooth.ru.md) и [сведения о поддержке моделей](docs/project-scope.ru.md).

## Текущая ветка

В этой ветке документации компонент пока использует домен `ha_tion_btle`. Для действующей установки скопируйте `custom_components/ha_tion_btle` из [ветки сопровождения](https://github.com/k-g-a/tion-breezer-ha/tree/maintenance/ha_tion_btle) в `/config/custom_components/` и перезапустите Core. Записи сохраняют прежний домен. Описанная ниже независимая версия готовится в [PR #13](https://github.com/k-g-a/tion-breezer-ha/pull/13).

## Установка

Если бризеры уже настроены в `ha_tion_btle`, до добавления новых записей прочитайте [инструкцию по переносу без повторного добавления устройств](docs/development-and-migration.ru.md).

После публичного выпуска откройте [репозиторий в Home Assistant](https://my.home-assistant.io/redirect/hacs_repository/?owner=k-g-a&repository=tion-breezer-ha&category=integration). Для Core 2025.6–2026.10 ссылка открывает HACS (его нужно предварительно установить), а для Core 2026.11+ — **Настройки → Marketplace**. Добавьте репозиторий как **интеграцию**, скачайте и при запросе перезапустите Core. Для пользовательского репозитория требуется подключение к GitHub. Включение в общий каталог проходит отдельно.

Для ручной установки независимой версии скопируйте каталог `custom_components/tion_breezer_2026` в `/config/custom_components/` и перезапустите Core. Новое устройство добавляется через **Настройки → Устройства и службы → Добавить интеграцию → Tion Breezer 2026**. Если сопряжение выполнено на хосте, снимите флажок **Need pair**.

## Работа Bluetooth

Для каждого бризера интеграция сохраняет одно активное соединение и последовательно выполняет опрос и команды. Каждое устройство занимает один слот адаптера. Для переподключения используются актуальный BLEDevice из HA и bleak-retry-connector. После обрыва соединение и подписки очищаются. Ожидание данных ограничено пятью секундами, интервал повторных попыток — одной минутой. Дубликаты фрагментов обрабатываются с проверкой длины кадра и CRC. После отключения питания бризера связь восстанавливается без перезапуска HA.

## Управление и диагностика 4S

Помимо питания, вентилятора, климата и источника воздуха, доступны выключатели звуковой и световой индикации, сброс ресурса фильтра и ошибок, признаки неисправности, замены фильтра, работы нагревателя, таймера и MagicAir. Отображаются температуры контроллера и силовой платы, мощность и номинал нагревателя, время работы устройства и вентилятора, счётчики расхода воздуха, максимальная скорость, источник команд и коды EC/WS.

При активной ошибке прошивка решает, принять ли команду. Отказ отображается как ошибка. Сброс не устраняет сохраняющуюся физическую неисправность. После переключения питания или источника воздуха на перемещение клапана отводится 15 секунд.

Boost у 4S запускает штатный таймер Turbo. По умолчанию он работает пять минут, длительность задаётся в параметрах интеграции. Оставшееся время сообщает сам бризер. При потере связи отсчёт продолжается, по окончании восстанавливается прежний режим. Вентилятор и климат показывают общее состояние Boost. Режимами Away и Sleep управляет HA.

## Происхождение и лицензии

Основа интеграции — [TionAPI/HA-tion](https://github.com/TionAPI/HA-tion), ревизия `7f41b890b2241f8541a23e13bb71093632d6109f`, и библиотека [TionAPI/tion_python](https://github.com/TionAPI/tion_python). Основной автор обоих проектов — [Игорь Ткаченко](https://github.com/IATkachenko). Анализ сбоев BLE и прототип встроенной библиотеки предоставил [@tms320 в обсуждении #154](https://github.com/TionAPI/HA-tion/issues/154). Включены [исправления слоя соединения](https://github.com/k-g-a/tion_python/pull/1) из ревизии `cf940bc21de629bf652762065b8466c39cdb0280`.

Интеграция распространяется по Apache-2.0, библиотека tion_btle — по LGPL-3.0-or-later. Подробности — в [NOTICE.md](NOTICE.md).
