# Перенос настроенных бризеров в Tion Breezer 2026

[English](development-and-migration.md)

Инструкция подходит для оригинальной HA-tion и этого форка с доменом `ha_tion_btle`. Скрипт переносит все настроенные бризеры за один раз. Сохраняются ID записей интеграции, сущностей и устройств, имена, параметры и сопряжение Bluetooth.

1. Скачайте резервную копию Home Assistant. Найдите **Tion Breezer 2026** в HACS (Core 2025.6–2026.10) или **Настройки → Marketplace** (Core 2026.11+) и установите интеграцию из каталога. См. [инструкцию по установке](../README.ru.md#установка). Пока оставьте старую интеграцию и её записи. Пропустите добавление нового устройства.
2. В HAOS откройте **Terminal & SSH** и выполните:

   ```sh
   sh /config/custom_components/tion_breezer_2026/migrate.sh
   ```

   При работе **по SSH на порту 22222 самого хоста HAOS** команда выглядит так:

   ```sh
   sh /mnt/data/supervisor/homeassistant/custom_components/tion_breezer_2026/migrate.sh
   ```

   Скрипт использует HA CLI и jq. Он остановит Core: старая интеграция освободит соединения BLE. Затем скрипт сохранит копии реестров, перенесёт записи и запустит Core. Остальные интеграции на это время тоже остановятся. В терминале появятся число перенесённых записей и путь к закрытому каталогу с оригиналами. Если под новым доменом уже есть записи, скрипт остановится до замены реестров.
3. Откройте **Настройки → Устройства и службы → Tion Breezer 2026**. Проверьте список бризеров, обновление показаний и переключение скорости. Если вы отключили запись вручную, включите её здесь. Автоматизации сохраняют прежние ID сущностей. Замените явные вызовы `ha_tion_btle.set_air_source` на `tion_breezer_2026.set_air_source` и обновите фильтры, ссылающиеся на старый домен.
4. После проверки удалите **старый пакет HA-tion** через HACS/Marketplace. При ручной установке удалите только каталог `custom_components/ha_tion_btle`. Выполните перезапуск, если его запросит HA. Оставьте каталог `custom_components/tion_breezer_2026` и перенесённые записи.

## Восстановление и другие варианты установки

Если скрипт сообщает о прерванной замене реестров, повторите команду с аргументом `--recover`: скрипт вернёт все три оригинала и запустит Core. Если аварийное завершение оставило блокировку, убедитесь, что процесс завершился, затем следуйте подсказке в терминале. Если Core остановлен и замена ещё не началась, запустите его командой `ha core start`. Для отката после завершённого переноса восстановите резервную копию HA, сделанную до миграции. Копии реестров содержат конфиденциальные данные.

**Home Assistant Container:** подключитесь по SSH к хосту Docker. Из каталога, смонтированного в контейнер как `/config`, выполните `sh custom_components/tion_breezer_2026/migrate.sh --container homeassistant`, подставив имя своего контейнера. Скрипт сверит путь монтирования, остановит и запустит контейнер, сохранит копии и выполнит тот же перенос. Требуются права на запись в том конфигурации, доступ к Docker и jq. Для восстановления прерванной замены добавьте `--recover`.
